WebUSB Probe

Does the board answer where Web Serial does not exist?

What this answers

Chrome on Android has no Web Serial, so the pages in this suite cannot open the board there. It does have WebUSB, and the board is a USB CDC device — a small protocol: claim the data interface, one control transfer to raise DTR, then bulk reads and writes. This page does exactly that and nothing else, so a failure names the step it failed at.

What decides it is whether anything else owns the device. On desktop Linux the kernel's cdc_acm driver does — it is what gives you /dev/ttyACM0 — and the browser is refused at open(), before it can even ask for the interface. On Android nothing usually claims it, which is the case worth testing.
