ESP32 Firmware Updater

Writes a merged image to an ESP32 over Web Serial, the way esptool.py write_flash 0x0 image.bin does and with the same code underneath — esptool-js, which resets the board into download mode, uploads its stub loader and verifies what it wrote. Needs a Chromium-based browser over https:// or http://localhost; nothing has to be done to the board first.

Notes

  • The board is put into download mode over DTR and RTS, and started again the same way when the write finishes. Both restart it, so its USB device goes and comes back — losing the port at the end is the firmware taking over, not a failure.
  • If it will not enter download mode by itself: hold BOOT, tap RESET, release BOOT — or, on a XIAO with no reset button, hold BOOT while plugging the cable in. Then connect and pick the port that appears.
  • Flashing erases only what it writes. A merged image covers bootloader, partition table and application, so nothing of the old firmware is left behind.
  • What was written is read back and compared by MD5 before the board is started.
